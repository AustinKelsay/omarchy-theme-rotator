# Changelog

All notable changes are documented here. Versions follow semantic versioning.

## 2.0.0 - 2026-08-30

- Rebuilt scheduling around an Omarchy-native background service.
- Replaced the standalone daemon with an idempotent `tick` interface.
- Added stable versioned JSON status and effective-config output.
- Added safe legacy-service migration and lifecycle installer.
- Added behavior tests, validation, ShellCheck, and GitHub Actions CI.
- Added domain language, architecture, contribution, and security docs.

## 1.0.0 - 2026-08-30

- Initial bar widget, helper daemon, and systemd user service.
